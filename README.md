# logistics-performance-dashboard
excel project Logistics Dashboard
## Overview
This Excel dashboard project analyzes shipment performance, carrier efficiency, delivery times, and logistics costs using a Kaggle logistics dataset.

## Tools Used
- Microsoft Excel
- Pivot Tables
- Pivot Charts
- IF Functions
- Data Cleaning

## Dashboard KPIs
- Delivery Rate: 85%
- Delayed: 10%
- Lost: 2%

## Key Insights
- Most shipments were successfully delivered
- Some destinations had higher logistics costs
- Carrier delivery times were relatively similar
- Delayed shipments highlight process improvement opportunities
